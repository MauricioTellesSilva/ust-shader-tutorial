Why is the sphere still gray?

The preview only uses the chain that reaches Material Output. Check Color → Base Color and BSDF → Surface. A disconnected node does not change the result.

What do the colored dots mean?

They are sockets: yellow carries color, gray carries numbers, green carries BSDF, blue carries normals, and purple carries displacement. The editor checks compatibility and prevents cycles.

How can I experiment after the lesson?

Change Color 1 and Color 2, try different scales, and compare Roughness values. Steps are re-evaluated whenever the graph changes, so they become pending again if you change the requested values.

How do I turn this page into a different lesson?

Create a definition in src/tutorials, register its identifier, and change data-tutorial in the HTML. The complete procedure, including code examples and tests, is in docs/tutoriais.md.
